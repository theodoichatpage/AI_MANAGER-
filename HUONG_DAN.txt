3. Lan dau se cai thu vien Windows mien phi; can Internet. Giu cua so nay mo.
4. Trinh duyet mo http://127.0.0.1:8765. Chon AUTOMATION TEST.

6. Kiem tra task PASS va mo screenshot. Bam Chay workflow CapCut de test tiep.

Gan workflow vao project: chon project trong Automation Test -> Dua workflow vao Queue du an -> CHAY TAT CA tren thanh chinh. Project TEST cu van la mo phong; khong tu doi thanh automation.

DUNG AGENT: dung queue + task, tat Agent. Khoi dong Agent khong tu chay lai task.
